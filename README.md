# 📊 Bank Churn Analysis

## 📌 Project Overview
This project analyzes customer churn in a bank to identify key factors that lead to customer attrition.

## 🎯 Objective
To understand customer behavior and identify patterns that influence churn, helping the bank improve retention strategies.

## 🛠 Tools Used
- SQL (Data Analysis)
- Excel (Data Cleaning)
- Power BI (Dashboard Visualization)

## 📂 Dataset Description
The dataset includes:
- Customer ID
- Age
- Balance
- Credit Score
- Geography
- Activity Status
- Number of Products
- Churn Status

## 📊 Key Insights
- Customers with low balance have higher churn rate
- Inactive customers are more likely to leave
- Germany shows higher churn compared to other regions
- Customers aged 40–60 show higher churn tendency

## 💡 Business Recommendations
- Improve engagement for inactive users
- Provide offers for low balance customers
- Focus on high-risk regions like Germany
- Introduce loyalty programs for mid-age customers

## 📌 Conclusion
Customer churn can be reduced by targeting high-risk groups with personalized strategies and improving customer engagement.
